# COVID-19 Tableau Visualizations Portal

## 📌 Project Overview
This repository contains the interactive business intelligence layers and executive reporting dashboards built from our processed global COVID-19 datasets. The visual frameworks are designed to track infection trajectories and mortality rates across localized borders.

⚙️ **Looking for the database layer?** View the underlying data pipeline and advanced query scripts in my [Covid Data Exploration SQL Repository](https://github.com).

---

## 📊 Core Dashboards Developed

### 1. Total Deaths per Continent
* **Visual Format:** Customized dynamic bar charts.
* **Analytical Focus:** Isolates and aggregates raw localized total mortality metrics across major global landmasses to highlight regional variance.

### 2. Global Infection Rate Tracking
* **Visual Format:** Automated global choropleth map virtualization.
* **Analytical Focus:** Dynamically scales color gradients across world borders to identify countries experiencing peak population infection percentages over the tracking timeline.
